# Original stage 4 path fixtures

Original artwork: three tiny PBM masks made for myembro. Top-down P1 PBM rows.
Expected paths are generated by **unmodified Potrace 1.16 C source**, mirror commit
`886392d351417d6753aff61de08e294d1506e502` (byte-identical trace.c/decompose.c to the
official 1.16 release). Copyright (C) 2001–2019 Peter Selinger, GPL-2.0-or-later.
The test caller is `tools/potrace/stage4_oracle.c`; its separate license is GPL-3.0-or-later.
Upstream license text: `engine/src/main/resources/licenses/potrace/COPYING`.

## Reproduce

```sh
tools/potrace/generate-stage4-goldens.sh /path/to/potrace-1.16
JAVA_HOME=/home/gosh2/.jdks/jdk-17.0.20.1+1 ./gradlew :engine:test --tests '*CurveFitterOracleTest'
```

The source argument must be an existing source tree. Nothing is downloaded or installed;
original sources are never edited. The script builds a temporary C caller with the system
compiler (`-std=c99 -O0 -DHAVE_INTTYPES_H=1 -DVERSION="1.16"`) and writes original
paths to `/tmp/myembro-port-out/editor/potrace-stage4/`. Tests use committed goldens,
so normal Gradle builds require no C compiler or native library.

Parameters are upstream defaults (`turdsize=2`, MINORITY, `alphamax=1`), except
**opticurve=0** to compare exactly the implemented stages 1–4. This is NOT a claim
that the default optimized final output (stage 5) is implemented or equivalent.
Tests compare path count, sign, area, full boundary and polygon indices exactly;
vertices, tags, control points, alpha/alpha0/beta with absolute tolerance 1e-10.

Cases: rectangle (smooth cubic), staircase (cubic + pointed corner), ring (outer
path + reversed hole). No stitch/PES/app integration or sew-out gate is involved.
This is a reproducible source comparison, not an independent quality decision.

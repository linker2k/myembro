# Adjustable filter oracle

Synthetic RGB bytes only, generated by `generate.py` with Pillow 11.3.0,
commit `89f1f4626a2aaf5f3d5ca6437f41def2998fbe09` (MIT-CMU; full license
in `engine/src/main/resources/licenses/pillow/LICENSE`). No personal images.

Sources: `src/PIL/ImageFilter.py:85–122`, `src/libImaging/RankFilter.c:29–60`,
`src/PIL/ImageEnhance.py:63–80`, `src/libImaging/Convert.c:44,230`,
`src/libImaging/Blend.c:21–78`. Tests compare every RGB byte, including borders,
narrow rasters, identity and clipping. SHA256SUMS records all fixture hashes.
Reproduce with a Pillow==11.3.0 Python environment; JVM tests require no Python.

# Frozen quality-gate v5 reference

`S1SAMPL.PES` is the public synthetic S1 sampler produced by our engine:
CIRCLE, SQUARE, TXT05 and TXT08 ("ABC 가나다", Noto Sans KR OFL font).
No personal/customer designs are included. Source project fixtures are in `../s1/`;
composition command: `tools/make_sewtest_sampler.py --help`.

The remaining nine inputs are deterministically generated by `GateV5ParityTest`.
`reference.json` contains SHA-256 identities, metrics and verdicts calculated by
`/tmp/myembro-quality-gate/gate.py` v5, with all source/threshold/POLICY hashes.
The strict Python verdict is used for app-generated output. Python v5 has no origin
option: the imported verdict is calculated separately by the explicit POLICY
adapter in `tools/refresh_sewout_gate_reference.py` (only density, repeat and lock
reasons become caution; density >30 and other hard errors remain blocked).

CI reads these committed snapshots; it needs neither Python nor `/tmp` fixtures.
Refresh explicitly using the two commands documented in the refresh script.
The test asserts byte identity, both verdicts and six observable metrics per file:
needle count, four-phase cell peak, consecutive peak, start/end missing locks,
and maximum stitch length. Invalid-length input must be blocked by both readers.
This checks automated policy parity; actual sewout remains the final acceptance.

# 기능별 UI 스토리 — Ink/Stitch 포팅 단계 적용

> 총괄 작성 2026-10-24. 엔진 포팅 상세는 `docs/inkstitch-port.md`, 이미지 파이프라인은 `docs/image-pipeline.md`.

## 진행 원칙

1. **한 번에 하나의 단계만 적용한다.** 한 단계는 엔진 기능, 그 기능을 쓰는 UI 조각, 품질 게이트, 실제 봉제 확인을 함께 묶는다. 다음 단계는 앞 단계의 사용자 검토가 끝난 뒤에 main에 들어간다. 개발 자체는 병렬로 계속해도 되지만, 병합과 릴리스는 단계 순서를 따른다.
2. **기본 화면은 단순하게, 고급 설정은 Ink/Stitch와 같게 둔다.** 기본 화면에는 조절값을 3개까지만 둔다. "고급"을 펼치면 Ink/Stitch의 파라미터가 모두 나온다. 이름은 한국어로 쓰고 원래 이름(`inkstitch:…`)을 작은 글씨로 함께 적는다. 기본값과 단위(mm)는 원본과 같게 한다.
3. **안전을 먼저 본다.** 앱이 만든 땀은 모두 봉제 점검 배지(통과·주의·차단)를 달고 나온다. 차단된 도안을 전송하려 하면 차단 이유를 보여 주고, 가능하면 "자동 수정" 버튼을 함께 준다.
4. **모바일의 장점을 쓴다.** 카메라 촬영, 한 손 조작(하단 시트·큰 터치 영역), 재봉틀로 바로 보내는 USB 전송, 인터넷 없이 동작을 살린다.
5. **화면 구조는 지금 그대로 둔다.** 홈(도안 목록) → 뷰어 → 편집기 → 시트 순서다. 새 전체 화면은 사진 → 자수 하나만 추가한다.

## 단계 순서

| 단계 | 엔진 (담당) | UI 스토리 | 사용자 검토 |
|---|---|---|---|
| S1 | 공통 후처리: 잠금 땀, 최소 땀·점프 길이, 트림 (worker) | US-1, US-2 | 자투리 천 시험 세트 봉제 |
| S2 | 새틴 기둥 전체 (letter) | US-3, US-4 | "Jung Min" 재봉제, 6–10mm 글자 |
| S3 | Ink/Stitch 자수 글꼴 (canvas, S2 필요) | US-5 | 글꼴 3종 봉제 |
| S4 | 채우기: 타타미와 그 변형 (model) | US-6 | 도형·윤곽 글자 채우기 봉제 |
| S5 | SVG 가져오기, 복제 (canvas) | US-7 | Ink/Stitch 예제 파일 열기 |
| S6 | 사진 → 자수 (editor) — 차별화 | US-8 | 사진 2–3장으로 봉제 |
| 공통 | 봉제 점검, 땀 재생 | US-0 | 매 단계 |

단계를 시작하려면 앞 단계의 게이트 통과, 릴리스, 사용자 봉제 확인이 모두 끝나 있어야 한다.

## US-0 봉제 점검과 땀 재생 (공통, 이미 일부 있음)

**사용자 이야기:** 처음 자수하는 사람으로서, 기계로 보내기 전에 이 도안이 안전한지 알고 싶다.

- 뷰어 상단에 배지를 하나 둔다: `통과` / `주의 2` / `차단`. 배지를 누르면 기존 봉제 점검 시트가 열린다.
- 차단 항목마다 문제가 있는 위치를 캔버스에 빨간 원으로 표시한다(예: 같은 자리에 바늘이 너무 많이 들어감). 앱이 만든 도안이면 **자동 수정** 버튼을 둔다. 수정 내용은 잠금 땀 추가, 짧은 땀 합치기, 밀도 낮추기다.
- **땀 재생**(Ink/Stitch 시뮬레이터에 해당): 뷰어 하단 슬라이더와 재생 버튼으로 바느질 순서를 재생한다. 속도는 1×, 4×, 16× 중에서 고른다. 실 색이 바뀌는 지점과 트림 지점을 눈금으로 보여 준다.
- 완료 조건: 차단된 도안을 전송하면 확인 창이 한 번 나온다. 배지는 전송 기록에도 남는다.

## US-1 앱이 만든 글자, 안전하게 바느질 (S1)

**사용자 이야기:** 글자를 넣어 보냈을 때 시작점에서 실이 엉키지 않아야 한다.

- 새로 생기는 화면은 없다. 기존 레터링과 편집기 결과에 공통 후처리가 자동으로 적용된다.
  - 실이 새로 시작될 때마다(시작, 트림 뒤, 색 변경 뒤) 시작 잠금 땀을 넣는다.
  - 실이 끝날 때마다 끝 잠금 땀을 넣는다.
  - 최소 땀 길이 미만의 땀은 합치고, 0 길이 땀은 지운다.
- 뷰어의 봉제 점검 시트에 "잠금 땀 N곳 · 짧은 땀 정리 M개" 요약 줄을 추가한다.
- 기존에 만든 `.myembro` 프로젝트는 다시 열 때 새 후처리로 다시 계산한다. 가져온 PES 파일은 손대지 않는다.
- 완료 조건: 품질 게이트를 통과하고, 시험 세트(러닝·새틴·채우기, 5/8/12mm 글자)를 SE400에서 엉킴 없이 봉제한다.

## US-2 잠금 땀·트림 설정 (S1)

**사용자 이야기:** 기본값으로 충분하지만, 필요하면 잠금 모양을 바꾸고 싶다.

- 설정 → "봉제" 섹션에 다음을 둔다.
  - 시작 잠금 / 끝 잠금 (`lock_start`, `lock_end`): 기본은 Ink/Stitch 기본값이다. 목록에는 Ink/Stitch의 잠금 종류가 모두 들어가고, 고를 때 작은 그림을 미리 보여 준다.
  - 최소 땀 길이 (`min_stitch_length_mm`)
  - 최소 점프 길이 (`min_jump_stitch_length_mm`)
  - 트림 기준 (`trim_after`, `force_lock_stitches`)
- 객체마다 따로 정하는 값(override)은 편집기의 객체 시트 → 고급에 둔다(US-4와 같은 자리).
- 완료 조건: 값을 바꾸면 미리보기와 봉제 점검이 바로 다시 계산된다.

## US-3 글자 새틴 품질 (S2)

**사용자 이야기:** 이름을 새틴으로 수놓았을 때 획 끝과 이음새에 바늘이 몰리지 않아야 한다.

- 레터링 시트는 지금 구성을 유지한다. 땀 종류 선택(러닝 / 새틴 / 채우기) 아래에 **권장 범위 표시**를 추가한다. 예: "이 글꼴은 새틴 8mm 이상 권장"(fontq2 기준).
- 권장보다 작은 크기를 고르면 "러닝으로 바꾸기" 칩을 보여 준다(PE-Design 소형 글자 방식과 같다).
- TTF 글꼴을 자동으로 새틴으로 바꾸는 기능은 기본에서 뺀다. Ink/Stitch의 convert-to-satin과 auto-route satin을 거친 결과만 새틴으로 쓴다.
- 완료 조건: "Jung Min" 사례가 게이트를 통과하고 실제 봉제에서도 문제가 없다.

## US-4 객체 땀 종류 시트 (S2에서 새틴부터, S4에서 채우기 추가)

**사용자 이야기:** 선택한 모양의 땀을 바꾸고 다듬고 싶다.

- 편집기에서 객체를 선택하면 하단 시트에 "땀" 탭이 생긴다.
  - **기본**(3개): 땀 종류, 밀도(새틴은 `zigzag_spacing_mm`, 채우기는 `row_spacing_mm`), 바탕 땀 켜기·끄기.
  - **고급**: 해당 Ink/Stitch 요소의 파라미터를 모두 보여 준다. 새틴이면 당김 보정, 짧은 땀, 분할, 바탕 땀 3종(가운데·윤곽·지그재그) 각각의 값, E·S·지그재그 변형이다.
  - 값을 바꾸면 미리보기를 바로 갱신하고, 바뀐 값 옆에 "기본값으로" 버튼을 둔다.
- 완료 조건: 같은 파라미터를 Ink/Stitch 공식판에 넣은 결과와 비교했을 때 동등성 기준(땀 수 ±5%, Hausdorff ≤0.2mm)을 만족한다.

## US-5 Ink/Stitch 자수 글꼴 (S3)

**사용자 이야기:** 이미 디지타이즈된 자수 전용 글꼴로 바로 예쁜 글자를 얻고 싶다.

- 글꼴 라이브러리에 **"자수 전용"** 탭을 첫 번째 탭으로 추가한다. 카드마다 다음을 보여 준다.
  - 실제 땀 미리보기
  - 권장 높이 범위(글꼴에 들어 있는 min/max)
  - 지원 문자: 한글 여부, 대문자만 지원하는지
- 한글을 지원하지 않는 글꼴로 한글을 입력하면 빠진 글자를 표시하고 "TTF 글꼴로 대체" 칩을 보여 준다.
- 완료 조건: 재배포 가능한 글꼴만 넣는다. 고르게 섞은 표본이 게이트를 통과한다.

## US-6 채우기 (S4)

**사용자 이야기:** 도형이나 굵은 글자 안을 채우고 싶다.

- 객체 땀 시트(US-4)에 채우기 종류를 추가한다. 순서는 타타미 → 윤곽 → 가이드 → 물결(meander) → 원형 → 선형 그라데이션 → 타탄이다.
- 기본 조절값은 각도, 밀도, 바탕 땀 세 가지다. 각도는 캔버스에 화살표 핸들을 두어 손가락으로 돌린다(모바일 전용 조작).
- 완료 조건: 구멍이 있는 도형과 작은 섬에서 짧은 땀 차단이 나오지 않는다.

## US-7 SVG 가져오기 (S5)

**사용자 이야기:** Ink/Stitch에서 만든 파일이나 SVG 그림을 폰에서 열고 싶다.

- 기존 가져오기 흐름에 `.svg`를 추가한다. 파일을 고르면 뷰어로 열린다.
- `inkstitch:*` 속성이 있으면 그 값을 그대로 쓴다. 속성이 없으면 "땀 자동 배정" 안내를 보여 주고, 확인하면 객체마다 땀 종류를 추정해 정한다.
- 지원하지 않는 요소는 목록으로 보여 준다(예: "텍스트 객체 2개는 경로로 변환되지 않아 제외").
- 복제(clone)는 편집기 객체 메뉴의 "복제"에 Ink/Stitch clone 의미를 그대로 따른다.

## US-8 사진 → 자수 (S6, 차별화)

**사용자 이야기:** 아이 그림이나 로고 사진을 찍어서 바로 자수 도안으로 만들고 싶다.

- 진입 경로: 홈 "새로 만들기" → "사진으로". 카메라나 갤러리에서 고른다.
- 흐름은 하나의 전체 화면에서 4단계로 진행한다. 화면 위에 단계 점을 표시한다.
  1. **자르기·바르게 펴기:** 자동 원근 보정을 하고 후프 크기 틀을 겹쳐 보여 준다.
  2. **단순화:** 슬라이더 두 개로 조절한다. "색 수"는 2–8이고, 각 색을 실 색 차트의 가장 가까운 색에 맞춘다. "디테일"은 작은 조각 제거와 윤곽 단순화를 정한다. 결과를 실시간으로 미리 본다.
  3. **땀 자동 배정:** 영역을 크기와 굵기에 따라 채우기, 새틴, 러닝으로 칠해 보여 준다. 영역을 탭해 땀 종류를 바꿀 수 있다.
  4. **확인:** 봉제 점검 배지와 땀 수, 예상 시간을 보여 준다. "편집기로"와 "뷰어로" 버튼을 둔다.
- 완료 조건: 결과 객체는 일반 편집기 객체이므로 US-4로 계속 다듬을 수 있다. 차단 결과는 내보낼 수 없다.

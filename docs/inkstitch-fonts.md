# Ink/Stitch predigitized embroidery fonts

The Ink/Stitch repository's `fonts/` is a submodule. The actual data is in
[inkstitch/embroidery-fonts](https://github.com/inkstitch/embroidery-fonts), where each `src/<폴더>`
contains `ltr.svg`, `font.json`, and `LICENSE`. This survey uses the following baseline.

- embroidery-fonts commit `c7e3a05c3d6f5c77b881c50f257851af9a8e9cb8` (2026-10 HEAD)
- 5 commits after `084eac0`, the submodule revision pinned by inkstitch commit `16e192849e619399ce8fdefb4c4d249dacdb4db1`
- Both repositories were cloned read-only; no Ink/Stitch code was executed.

### Evaluation principles
- **The LICENSE file takes priority.** Where it differs from font.json, LICENSE governs; the discrepancy is recorded in the notes.
  - `precious`: font.json says OFL; LICENSE says GPL-3.0
  - `cogs_KOR`: font.json says CC-BY-SA; LICENSE says CC BY 4.0
  - `nautical`: says NC but links to a by-sa URL
- **NC (noncommercial) is not permitted.** Anyone may sell a GPL app, so distributing noncommercial data in our catalog would create conflicting conditions.
- **ND (no derivatives) is also not permitted.** We cannot assert that resizing and stitch generation do not constitute an adaptation.
- **For CC BY-SA, both the adaptation and the original font were examined.**
  - Permitted if newly created for Ink/Stitch, or if the original is public domain, OFL, Bitstream Vera, Hershey, or CC BY-SA.
  - Conditional if the original is freeware described as "free for personal and commercial use" and the only evidence is email permission received by an Ink/Stitch contributor. We cannot confirm that the permission extends to redistribution in a third-party app. The original `learning_curve` explicitly states "no resale; no inclusion in CD-ROM collections."
- **The app does not package these files in the APK.** They are downloaded to the user's device from pinned commit URLs, and LICENSE is saved alongside the font.
  - CC BY-SA data is treated as a separate work, not mixed into the GPL code.
  - OFL's Reserved Font Name condition applies when modifying and redistributing files; we download the original files unchanged.

## Catalog approach
- `app/src/main/assets/fonts/inkstitch-catalog.json` is separate from the existing `catalog.json`.
  - Generator: `tools/inkstitch_catalog.py`
  - Inputs: the checkout and the engine survey results (`InkStitchSurveyTool`)
- Each entry contains `raw.githubusercontent.com/<40자 commit>/...` URLs and sha256 values for all three files: `ltr.svg`, `font.json`, and `LICENSE`.
- `InkStitchFonts.download` saves the files only after verifying all three. If any verification fails, nothing is retained.
- Recommended heights come from the digitizer's `min_scale`/`max_scale` in font.json, converted to the app's height reference (the ink height of the reference character 'H'). This is the range tested by the original author, not a value from our analysis.
  - The 9 'small/tiny' variants that allow heights below 6mm are marked `CAUTION`.
  - The 12 fonts whose font.json requires 60wt thread and a size 60 needle are marked `thinThreadRequired`. This aligns them with the PE-Design measurements (ordinary outlines prohibited at 5mm or below).
- Users download only the fonts they select. The app contains just one actual-stitch preview image per font.

## Parser and sewing design
The engine code consists of two files (S3 scope, independent of the SVG import model).
- `engine/.../inkstitch/lettering/InkStitchFont.kt`: a minimal SAX streaming parser for glyph layers
- `InkStitchLettering.kt`: layout and sewing calls

### Reading
- Reads through SAX streaming. DOCTYPE and external entities are rejected.
- Each `GlyphLayer-<문자>` group represents a glyph. Names are normalized to NFC; names containing multiple characters are treated as ligatures. If multiple files contain the same glyph, the later one wins.
- Coordinates are **px(1/96 in)**, as in Ink/Stitch. The root viewBox transform (svg/units.py) is composed with ancestor `transform` values.
- Styles inherit fill, stroke, stroke-width, fill-rule, and fill-opacity. During rendering, paths without fill receive a line width of 1px, as in _set_style.
- Skips the following: `display:none` (except on the glyph layer itself), `defs`/`clipPath`/`mask`/`symbol`, connectors, command symbols, and paths with Ink/Stitch pattern or guide markers.
- Clones (`<use>`) and shape elements are counted but not sewn in this version. No catalog fonts are affected.
- Glyph width and the starting point (minX) are measured from all paths except connectors (connection-end), as in glyph.py.
- Element classification follows nodes.py: a fill produces fill stitches; a stroke produces satin (`satin_column`) or running stitches.
- All satin subpaths and nodes are passed through unchanged; the satin port (`SatinColumn.fromSubpaths`) identifies rails and rungs and generates node-based rungs.
- The baseline is the `baseline` guide. The bottom of 'H' is used only when no guide is present.

### Sewing
Each element's `inkstitch:*` values are read, with Ink/Stitch defaults used when absent. Stitch algorithms call the shared ports.

| Element | Call |
|---|---|
| Satin | `inkstitch.elements.SatinColumn.fromSubpaths` (embro-letter port). Attributes are transferred to identically named `SatinParameters` fields |
| Fill | `inkstitch.stitches.InkAutoFill` twice (underlay: angle+90°, row spacing multiplied by 3; top stitches: `angle`, `row_spacing_mm` 0.25, `max_stitch_length_mm` 3, `staggers` 4) |
| Running | `inkstitch.stitches.InkRunning.even` (2.5mm, tolerance 0.2mm), `repeats`, `bean_stitch_repeats` |
| Shared | Jumps between elements; trim+color change when the color changes; respects `trim_after`/`stop_after`. Locks, short-movement connections, and minimum length use `StitchPlanFinisher` |

Layout matches Ink/Stitch lettering (font.py): kerning, `horiz_adv_x`, spaces, `leading`, `letter_case`, reverse sewing of odd-numbered lines (back_and_forth), and per-line bbox alignment. Height is based on the ink height of 'H'; only the geometry scales proportionally.

### Catalog inclusion criteria
Only fonts that are redistributable, can sew every element, and generate successfully at both the recorded minimum and maximum heights are included. As of 2026-10-24, there are 72 fonts (letter 1c8f59d). Each height range is the longest continuously passing interval in the sweep (`InkStitchFontSweep`, letter engine): the recorded range min..min(max, 60mm), at 2mm intervals, with 3 text samples evaluated by SewoutCheck (worker 2b89226). 60mm is the app's character-height cap for a 100×100 hoop. Hoop overflow does not narrow the range. Reasons for omitted fonts appear in the last column of the table below.

### Validation
- `InkStitchFontTest`: checks synthetic SVGs.
  - viewBox unit conversion; exclusion of hidden elements, connectors, and commands; satin subpath and parameter forwarding; fill rules and parameters
  - Rendering at 20mm height; layout advance, kerning, and spaces; reverse odd-numbered lines; alignment; font colors and a single thread; DOCTYPE rejection
- `InkStitchCatalogTest`: checks that all URLs are pinned to commits, sha256 format, the license allowlist, and height ranges.
- `InkStitchSurveyTool` (opt-in): parses and renders the entire checkout, writing tables and PNGs outside the repository.
  - All 132 `ltr.svg` files parse without exceptions (the largest font takes 1.5 seconds).
  - The median 'H' height / font.json `size` is 1.01, evidence that unit conversion is correct.
  - The sha256 of one downloaded file (glacial_tiny) matches the catalog value.

### Remaining work
- App integration (complete): shown at the front of the font library with an 'Embroidery fonts' filter and badge; once downloaded, lettering uses it as a `FontKind.INKSTITCH` TextObject.
  - Projects store only the font id; installed fonts are resolved through `InkStitchFontRegistry`. Deleting a font leaves the corresponding text with empty stitches and a warning.
  - The lettering screen hides stitch type, thread weight, fill settings, and curved placement, and shows the tested height range. Quality badges are determined from that range.
  - Changing the font resets spacing to 0 to avoid breaking script connections. Per-character colors are not yet applied (covered under multicolor fonts).
- Algorithms being ported from Ink/Stitch by embro-letter can be plugged in unchanged. Parser results (`InkSatin` sections, `InkFill`, `InkRun`, and original parameters) are separate from sewing code, so only `InkStitchLettering.runs` needs to change.
- Implementing unsupported methods will expand the catalog. Cross-stitch alone would add 17 fonts rated as permitted; manual elements (7 elements in dejavufont, and paquerette) are also candidates.
- The 8 conditional fonts can be added if the original authors grant permission for app redistribution.

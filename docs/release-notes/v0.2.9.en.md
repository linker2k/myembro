# myembro v0.2.9 (draft)

> Draft — not released. Items marked **pending** depend on branches not yet merged.

## New
- **Ask AI** — edit the design with any chatbot app (Gemini, ChatGPT, Claude, …). No account or API key; the app sends a text summary of the design (no stitches, pictures or files), checks the reply, shows before/after and the sew-out check, and applies it as one undo step. Deleting, saving, sharing and USB transfer are always confirmed in the app.
- **PC control (MCP)** — a stdio MCP host lets Claude Code, Codex CLI and other MCP clients drive the same commands on a PC. Setup: `docs/agent/mcp.md`.
- **English UI fonts** — bundled lettering fonts have English names in English, and the default phrase follows the app language ("Spring" / "봄날").
- **Documentation** — English README/AGENTS, Korean README.ko.md, user guide in English and Korean with screenshots.

## Fixed
- Canvas size label after moving a design showed 0.1 mm more than the real size (e.g. 35.6 vs 35.5 mm). It now matches the properties field and the PEC header.

## Changed (internal)
- Editor edits and undo/redo go through shared engine commands (`EditSession`); text preparation and the Hangul centerline chain moved into the engine. No intended change to stitches.

## Known limitations
- SE400: no automatic thread cutting; trim travel threads by hand.
- Development signing key; a reinstall will be needed when the official key is introduced — take a full backup first.
- Ask AI can add text only in fonts already on the phone.

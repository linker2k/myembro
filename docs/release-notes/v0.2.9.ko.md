# myembro v0.2.9 (초안)

> 초안 — 아직 배포 전. **대기** 표시 항목은 아직 병합되지 않은 브랜치에 달려 있다.

## 새 기능
- **AI에게 맡기기** — 어떤 챗봇 앱(Gemini, ChatGPT, Claude 등)으로든 도안을 고친다. 계정·API 키 없음. 앱은 도안의 글 요약만 보내고(땀·그림·파일은 보내지 않음), 답을 검사해 전/후 그림과 봉제 점검을 보여 준 뒤 되돌리기 한 단계로 적용한다. 삭제·저장·공유·USB 전송은 항상 앱에서 직접 확인한다.
- **PC에서 제어(MCP)** — stdio MCP 호스트로 Claude Code, Codex CLI 등 MCP 클라이언트가 PC에서 같은 명령을 실행한다. 설정: `docs/agent/mcp.md`.
- **영어 화면 글꼴 이름** — 번들 레터링 글꼴 이름이 영어 화면에서 영어로 나오고, 기본 문구가 앱 언어를 따른다("Spring" / "봄날").
- **문서** — 영어 README/AGENTS, 한국어 README.ko.md, 스크린샷이 들어간 영어·한국어 사용 설명서.

## 고침
- 도안을 옮긴 뒤 캔버스 크기 표시가 실제보다 0.1mm 크게 나오던 문제(예: 35.6 대 35.5mm). 이제 속성 칸·PEC 헤더와 같다.

## 바뀜(내부)
- 편집과 되돌리기/다시 실행이 엔진 공통 명령(`EditSession`)을 거친다. 글자 준비와 한글 중심선 처리가 엔진으로 옮겨졌다. 땀 결과는 바뀌지 않도록 했다.

## 알려진 한계
- SE400: 자동 실 절단 없음. 이동 실은 손으로 정리.
- 개발용 서명 키. 정식 키로 바뀔 때 재설치가 필요하므로 먼저 전체 백업.
- AI에게 맡기기는 휴대폰에 이미 있는 글꼴로만 글자를 추가할 수 있다.

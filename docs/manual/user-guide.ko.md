# myembro 사용 설명서

[English](user-guide.md) | **한국어**

> 목차 초안. 스크린샷은 `/tmp/myembro-manual-shots/`에서 가져올 예정.

1. 시작하기 — 설치, 시작 화면, 보관함
2. 도안 보기 — PES/PEC/DST 열기, 확대, 재생, 통계, 후프
3. 편집기 — 도안·글자 배치, 크기, 회전, 프로젝트 저장
4. 레터링 — Ink/Stitch 글꼴, TTF 글꼴(한글), 단선 보통/굵게, 글꼴 내려받기
5. 이모지 — 검색(한국어 포함), 크기 슬라이더
6. 사진→자수 — 자르기, 실루엣, 외곽선, 컬러 그림, 크기
7. 봉제 점검 — 무엇을 왜 막는가
8. 자수기 전송 — SE400 USB 전송, 전송 기록, 이동 실 정리, SE600/SE700
9. 설정 — 백업/복원, 앱 정보
10. 알려진 한계

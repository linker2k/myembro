## 1. 시작하기

최신 GitHub pre-release에서 APK를 설치합니다. 앱을 열면 홈 화면이 나옵니다.

![홈 화면](../images/manual/01-home.png)

- **새 프로젝트** 카드: 기본 후프(100×100mm, 4×4in)를 보여 줍니다. **새 프로젝트 시작**을 누릅니다.
- **최근 프로젝트**: 저장한 도안과 프로젝트가 표시됩니다. **모두 보기**는 전체 목록, **도안 가져오기**는 휴대폰의 PES/PEC/DST 파일을 엽니다.
- **샘플 도안**: 바로 열어 볼 수 있는 내장 도안입니다.
- 아래 막대: **홈**, **도안**, **만들기**, **설정**. 오른쪽 위 톱니바퀴도 설정을 엽니다.

## 2. 새 프로젝트 시작

**새 프로젝트 시작**을 누르면 다섯 가지 시작 방법이 나옵니다.

![새 프로젝트 시트](../images/manual/02-new-project.png)

| 항목 | 누르면 |
|---|---|
| 빈 후프에서 시작 | 후프를 고르면 빈 편집기가 열립니다 |
| 내 도안으로 시작 | 저장한 도안을 고르면 그 도안으로 편집기가 열립니다 |
| 사진/그림 | 사진·그림을 실루엣, 외곽선 또는 컬러 자수로 만듭니다(5장) |
| 이모지로 | 공개 이모지 그림을 자수로 만듭니다(6장) |
| 글자로 시작 | 레터링 화면이 열립니다(4장) |

## 3. 편집기

![myembro 로고를 연 편집기](../images/manual/03-editor-logo.png)

- 위쪽: 뒤로, 실행 취소/다시 실행, 메뉴. 그 아래 후프 칩(예: **후프 100×100mm**), 객체 수, **저장** 버튼.
- 왼쪽 도구: 선택, 이동(손), 화면 맞춤, 격자.
- **레이어** 패널: 도안과 글자는 각각 레이어입니다. 눈 아이콘으로 보이기/숨기기, **+**로 추가합니다.
- 객체를 눌러 선택하고 모서리 핸들을 끌어 크기를 바꿉니다. 크기 표시는 mm와 인치를 함께 보여 줍니다.
- 아래 시트 탭 **변형**, **스티치**, **색상**. 변형 탭에서 **가로 (mm)**/**세로 (mm)**를 입력하고(자물쇠는 비율 고정), 회전·뒤집기를 정한 뒤 **적용**을 누릅니다.
- 아래 막대: **선택**, **도안**(도안 추가), **변형**, **글자**, **레이어**.

기본 후프는 100×100mm입니다. 도안은 후프 안에 있어야 합니다. 좌표는 0.1mm 단위로 0–999이므로 디자인 최대 크기는 99.9mm이고, 앱이 자동으로 지킵니다.

## 4. 레터링

![글꼴 목록](../images/manual/04-font-library.png)

1. 편집기에서 **글자**를 누릅니다(또는 **글자로 시작**).
2. 글자를 입력하고 글꼴 목록을 엽니다. 필터: **전체**, **한글**, **영문**, **필기체**, **단선**, **외곽선**. **+ 내 폰트 추가**로 내 TTF 글꼴을 넣을 수 있습니다.
3. 글꼴은 각 오픈소스 저장소에서 받아 검증한 뒤 사용합니다. 글꼴 카드의 내려받기 버튼을 누르고, **라이선스**로 라이선스를 보고, 하트로 즐겨찾기합니다. 입력한 한글을 지원하지 않는 글꼴은 카드에 표시됩니다.
4. 글자 높이를 정하고 후프 위에 배치합니다.

앱이 자동으로 정하는 것:
- **땀 종류.** TTF 글꼴(한글 포함)은 글자 크기에 따라 새틴·채우기·러닝 중 하나를 앱이 고르고, 안전하게 봉제되는 크기만 허용합니다.
- **Ink/Stitch 글꼴**(검증된 72종)은 새틴으로 수놓습니다.
- **단선 글꼴**은 **보통**(1회)과 **굵게**(Ink/Stitch 빈 스티치, 3회)가 있습니다. 원본 글꼴이 같은 구간을 두 번 지나는 곳은 굵게에서 6회가 될 수 있습니다.

## 5. 사진→자수

**사진/그림**을 고르고, 그림을 선택해 자른 뒤 모드를 정합니다.

- **실루엣**: 한 색, 채우기.
- **외곽선**: 한 색, 윤곽선.
- **컬러 그림**: 그림을 여러 실 색으로 추적합니다. 흑백 옵션이 있습니다.

슬라이더로 자수 크기를 정하고 미리보기를 확인한 뒤 편집기로 넘어갑니다. 아주 작은 영역은 합쳐서 없애고, 영역마다 땀 종류(채우기·새틴·러닝)를 자동으로 고릅니다. 안전하게 수놓을 수 없는 영역은 빼고 몇 개를 뺐는지 알려 줍니다.

## 6. 이모지

**이모지로**를 고르고 검색합니다(유니코드 CLDR 기반 한국어 검색 지원). 이모지를 고른 뒤 슬라이더로 크기를 정합니다(사진 화면과 같은 슬라이더). 일부 이모지는 크게 만들면 작은 색 영역이 빠질 수 있어, 앱은 모든 색이 남는 크기 범위만 제공합니다.

## 7. 뷰어: 재생과 통계

도안을 열면 실 색, 확대·이동, 후프 윤곽, 한 땀씩 재생, 통계(땀 수·크기·색·트림·예상 시간)를 볼 수 있습니다. PES (v1–v10), PEC, DST를 열 수 있습니다.

## 8. 봉제 점검

앱이 만든 모든 도안은 저장·전송 전에 실제 봉제 실패를 일으키는 조건을 검사합니다.

- 0.5mm 칸 하나에 바늘이 너무 많음
- 같은 점에 연속으로 바늘이 들어감
- 시작·끝 잠금 땀 누락
- 12.0mm보다 긴 땀
- 파일 오류, 또는 후프 밖 땀(0.1mm 단위 0–999)

하나라도 걸리면 저장·전송을 막고 이유를 보여 줍니다. 가져온 PES 파일은 바이트 그대로 유지합니다.

## 9. 자수기로 보내기

**Brother SE400 (USB 케이블):** 휴대폰과 SE400을 USB 케이블로 연결해 도안을 바로 보냅니다(실기 확인). 보낸 기록은 전송 기록에 남습니다.

**SE400 주의:** 자동 실 절단이 없습니다. 색·위치 사이 이동 실이 잘리지 않으므로 봉제 후 손으로 정리하세요. 앱이 안내합니다.

**SE600/SE700:** 매뉴얼 기준 기종 프로필(100×100mm, USB 메모리)이며, 실기 전송은 아직 확인하지 않았습니다.

## 10. 백업과 복원

**설정**의 전체 백업은 도안·프로젝트·다운로드 글꼴·설정을 ZIP 하나로 저장하고, 복원은 그 ZIP을 다시 읽어 옵니다.

**지금 백업해 두세요.** 현재 APK는 개발용 서명 키로 서명되어 있습니다. 정식 서명 키로 바뀌면 새 버전을 기존 앱 위에 설치할 수 없어 한 번 삭제 후 재설치해야 하고, 이때 앱 데이터가 지워집니다. 재설치 후 ZIP으로 복원하세요.

<!-- shot: 15 backup/restore -->

## 11. 앱 정보와 알려진 한계

**설정 → 앱 정보**에서 앱 버전과 정보를 볼 수 있습니다. myembro는 GPL-3.0-or-later입니다.

- SE400: 자동 실 절단 없음. 이동 실은 손으로 정리.
- 서명 키 변경: 한 번 삭제·재설치 필요. 먼저 백업.
- SE600/SE700: 실기 전송 미확인.

앱에는 다크 테마도 있습니다.
